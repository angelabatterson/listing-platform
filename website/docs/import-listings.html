Already selling on eBay or Etsy? Import your live listings so they're in your Relistic inventory and start syncing straight away. You don't have to list them again.

Import

  1. Connect the store first (see Connect your stores).
  2. Click your name at the bottom of the left menu, then Stores.
  3. Under eBay or Etsy, click Import my listings.
  4. Keep the page open while it works. It reads your listings a page at a time and adds each one to Inventory.

Good to know

  • No duplicates. If a listing has the same SKU or title as an item already in Relistic, it's linked to that item instead of copied. If you sell the same item on both eBay and Etsy, import one store, then the other, and they'll be joined.
  • Run it again any time. Click Import again to pick up new listings. Listings imported before are skipped.
  • Listings with variations (several sizes or colors in one listing) are skipped for now.
  • Plan limits. Imported items count toward your plan's active listings. The import stops at your limit.

eBay listings made on eBay's own website are synced for price and quantity only. Relistic ends them when the item sells elsewhere and relists them if it comes back, but their title, photos and description stay as they are on eBay.

After importing, you can tick more stores on each item to crosslist it there too.
