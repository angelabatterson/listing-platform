Relistic keeps every listing matched to the item it came from. Here's exactly what happens, and when.

When you save an item

  • Ticked stores where it isn't listed yet: Relistic creates the listing.
  • Stores where it's already listed: Relistic updates the title, description, price and quantity.
  • Stores you un-ticked: Relistic ends the listing there.

The result for each store shows on the item and in Activity. If something goes wrong, Relistic explains it in plain words, for example a missing category, so you can fix it and click Sync now.

When an item sells

  1. Relistic finds out about the sale. Etsy tells Relistic within seconds. eBay, Shopify and TikTok Shop are checked every 5 minutes.
  2. The item's quantity goes down by the number sold.
  3. If there are some left, every other store is updated to the new quantity.
  4. If none are left, the item is marked Sold and ended on every other store.
  5. The sale shows on your Dashboard, the buyer appears in your CRM, and the order is ready on the Shipping page.

Chrome extension stores (Poshmark, Depop, Mercari, Grailed, Facebook Marketplace and Whatnot) can't be changed by other apps. When an item sells elsewhere, the extension shows a Take down job and opens the listing for you to remove. See The Chrome extension.

Overselling

If two stores sell the same item before Relistic can take it down, Relistic counts each sale once and flags the extra one as an oversell in Activity, so you can contact the buyer quickly.

The Activity log

Click Activity in the left menu to see everything Relistic has done: each listing created, updated or ended, each sale, and any problems. It's the first place to look if something doesn't look right on a store.
